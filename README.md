# Disney Movie Info: *The Lion King* (1994)

## Overview
*The Lion King* is a 1994 American animated musical drama film produced by Walt Disney Feature Animation and released by Walt Disney Pictures. It was directed by Roger Allers and Rob Minkoff, with a screenplay by Irene Mecchi, Jonathan Roberts, and Linda Woolverton.

### Key Facts:
- **Release Date**: June 15, 1994
- **Genre**: Animation, Adventure, Drama, Musical
- **Director(s)**: Roger Allers, Rob Minkoff
- **Music by**: Hans Zimmer
- **Voice Cast**:
  - Matthew Broderick as Simba (young and adult)
  - James Earl Jones as Mufasa
  - Jeremy Irons as Scar
  - Whoopi Goldberg as Shenzi
  - Nathan Lane as Timon
  - Ernie Sabella as Pumbaa
